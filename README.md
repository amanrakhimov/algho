# algho

Материалы по курсу «Продвинутые алгоритмы и их сложность»: алгоритмы top-k и top-p sampling для языковой части vision-language моделей.

- `latex/` — псевдокод top-k и top-p на LaTeX (`algorithmicx` и `algorithm2e`, исходники и PDF)
- `docs/probability_explained.md` — как нейросеть получает вероятности следующего слова (сквозной пример с расчётами)
- `code/prob_pipeline.py` — код примера из документа (`python prob_pipeline.py`)
