# Как нейросеть получает вероятности следующего слова

Документ разбирает весь путь от текста «Кошка сидит на» до вероятностей слов-продолжений («диване» 42%, «полу» 24% и так далее). Все шаги посчитаны на одном сквозном примере. Числа придуманы для иллюстрации и проверены кодом ([`../code/prob_pipeline.py`](../code/prob_pipeline.py)); в настоящей модели их подбирает обучение.

## Общая схема

Цепочка из семи шагов. Первые четыре выполняет нейросеть, последние три относятся к выбору слова.

| № | Шаг | Что на входе | Что на выходе |
|---|---|---|---|
| 0 | Токенизация | текст | номера токенов |
| 1 | Embedding | номера токенов | по вектору на каждое слово |
| 2 | Attention | векторы всех слов фразы | один вектор контекста **h** |
| 3 | Логиты | h | по баллу на каждое слово словаря |
| 4 | Softmax | баллы | вероятности (сумма равна 1) |
| 5 | Top-k / top-p | вероятности | короткий список кандидатов |
| 6 | Выбор слова | список кандидатов | одно слово |

После выбора слово добавляется к фразе, и весь цикл повторяется для следующего слова.

## Шаг 0. Токенизация

Модель не читает буквы. Токенизатор (обычно BPE) режет текст на кусочки из фиксированного словаря и заменяет каждый кусочек номером, например «на» → 1204. Реальный токенизатор может разбить редкое слово на несколько частей. В примере для простоты считаем, что одно слово равно одному токену.

Словарь строится один раз до обучения по большому корпусу текстов. Он содержит порядка 32 000 токенов и после этого не меняется. Слова «луна» и «облако» берутся именно оттуда.

## Шаг 1. Embedding: слова становятся числами

У каждого токена в таблице есть своя строка из чисел, это его вектор (embedding). В реальной модели в строке сотни или тысячи чисел, в нашем примере три: `[живое, поза, место]`.

| слово | вектор |
|---|---|
| Кошка | [1.0, 0.0, 0.0] |
| сидит | [0.0, 1.0, 0.0] |
| на | [0.0, 0.5, 1.0] |

Векторы слов не вписывает человек. Они учатся вместе со всей моделью. Порядок слов в реальной модели добавляется отдельно (позиционное кодирование), в примере мы его опускаем.

## Шаг 2. Attention: слово «на» собирает смысл фразы

Мы хотим получить вектор **h** для последней позиции. Он должен нести смысл всей фразы «Кошка сидит на». Для этого слово «на» смотрит на каждое слово фразы (включая себя) и берёт у него информацию в нужной пропорции.

Для простоты запрос, ключ и значение каждого слова совпадают с его вектором. В реальной модели они получаются умножением вектора на три обученные матрицы Wq, Wk, Wv.

**2.1. Сравнение.** Запрос слова «на» это `q = [0, 0.5, 1]`. Скалярное произведение с каждым словом, затем деление на √3 ≈ 1.732 (размерность равна 3):

| слово | q · вектор | после деления на √3 |
|---|---|---|
| Кошка | 0·1 + 0.5·0 + 1·0 = 0 | 0.000 |
| сидит | 0·0 + 0.5·1 + 1·0 = 0.5 | 0.289 |
| на | 0·0 + 0.5·0.5 + 1·1 = 1.25 | 0.722 |

**2.2. Softmax превращает баллы в доли внимания.** Формула: `доля_i = e^{балл_i} / Σ e^{балл_j}`. Читается так: возводим e (≈ 2.718) в степень каждого балла, складываем результаты и делим каждый на сумму.

| слово | e^балл | доля |
|---|---|---|
| Кошка | 1.000 | 0.228 |
| сидит | 1.335 | 0.304 |
| на | 2.058 | 0.468 |

Сумма e^балл равна 4.393, сумма долей равна 1. Слово «на» уделяет 23% внимания слову «Кошка», 30% слову «сидит» и 47% самому себе.

**2.3. Смешивание.** Каждый вектор умножается на свою долю, затем всё складывается:

| слово | доля × вектор |
|---|---|
| Кошка | 0.228 × [1, 0, 0] = [0.228, 0, 0] |
| сидит | 0.304 × [0, 1, 0] = [0, 0.304, 0] |
| на | 0.468 × [0, 0.5, 1] = [0, 0.234, 0.468] |
| **сумма** | **h = [0.228, 0.538, 0.468]** |

В векторе h теперь смешан смысл всех трёх слов.

## Шаг 3. Что ещё делает настоящая модель до логитов

Наш пример показывает один attention без лишнего. В настоящей модели вокруг него есть ещё несколько вещей:

- **Три матрицы Wq, Wk, Wv.** Они обучены и решают, какие признаки слова считать запросом, ключом и значением.
- **Головы.** Attention выполняется параллельно 8–32 раза с разными матрицами, потом результаты склеиваются.
- **Остаточная связь и сеть FFN.** К результату добавляется исходный вектор, затем он проходит через небольшую нейросеть.
- **Слои.** Всё это повторяется десятки раз. Каждый слой берёт результат предыдущего. Вектор h, который мы используем, это результат последнего слоя.
- **Причинная маска.** Слово видит только предыдущие слова, будущие закрыты. Для последнего слова это ничего не меняет.

## Шаг 4. Логиты: сравниваем h со всеми словами словаря

У каждого слова словаря есть второй вектор, из выходной матрицы W_out. Логит это скалярное произведение вектора h на вектор слова: `логит = h · W_out[слово]`.

| слово | вектор из W_out | расчёт | логит |
|---|---|---|---|
| диване | [0.0, 3.0, 0.5] | 0.538·3 + 0.468·0.5 | 1.849 |
| полу | [0.0, 2.0, 0.5] | 0.538·2 + 0.468·0.5 | 1.310 |
| крыше | [0.0, 1.0, 1.5] | 0.538·1 + 0.468·1.5 | 1.241 |
| луне | [−1.0, 0.5, 0.0] | −0.228 + 0.269 | 0.041 |
| облаке | [−1.5, −0.5, 0.5] | −0.342 − 0.269 + 0.234 | −0.376 |

Чем лучше слово подходит к контексту, тем выше балл. Здесь показаны пять слов, а модель делает это для всех слов словаря, около 32 000 скалярных произведений за один шаг.

## Шаг 5. Softmax: баллы становятся вероятностями

Формула с температурой T: `p_i = e^{z_i / T} / Σ e^{z_j / T}`.

При T = 1:

| слово | логит | e^логит | вероятность |
|---|---|---|---|
| диване | 1.849 | 6.355 | 0.417 |
| полу | 1.310 | 3.706 | 0.243 |
| крыше | 1.241 | 3.459 | 0.227 |
| луне | 0.041 | 1.042 | 0.068 |
| облаке | −0.376 | 0.687 | 0.045 |

Сумма e^логит равна 15.249, сумма вероятностей равна 1.

### Температура

Температура делит логиты на T до softmax. При T = 1 ничего не меняется. Температура меняет «остроту» выбора:

| слово | T = 0.5 | T = 1.0 | T = 2.0 |
|---|---|---|---|
| диване | 0.597 | 0.417 | 0.309 |
| полу | 0.203 | 0.243 | 0.236 |
| крыше | 0.177 | 0.227 | 0.228 |
| луне | 0.016 | 0.068 | 0.125 |
| облаке | 0.007 | 0.045 | 0.102 |

При T < 1 лидер становится увереннее (разрыв между логитами растёт), при T > 1 выбор становится случайнее (разрыв сжимается).

## Шаг 6. Top-k и top-p: оставляем только подходящие слова

Здесь начинаются фильтры, которые мы писали в псевдокоде. Нейросеть к этому шагу уже закончила работу.

**Top-k (k = 2).** Оставляем два самых вероятных слова: диване 0.417 и полу 0.243. Сумма 0.660, пересчитываем на 1:

- диване: 0.417 / 0.660 = **0.631**
- полу: 0.243 / 0.660 = **0.369**

**Top-p (p = 0.9).** Идём по словам от самого вероятного и копим сумму: 0.417, затем 0.660, затем 0.887. Это меньше 0.9, поэтому берём ещё «луне» и получаем 0.955. Остаются четыре слова, пересчитанные на 1: диване 0.436, полу 0.255, крыше 0.238, луне 0.072. Слово «облаке» отбрасывается.

Top-k всегда оставляет ровно k слов, top-p оставляет столько слов, сколько нужно, чтобы сумма дошла до p. Поэтому при уверенной модели список короткий, при неуверенной длинный.

## Шаг 7. Выбор слова

Из оставшихся слов выбирается одно случайно, пропорционально их вероятностям. Для top-k выше «диване» выпадет в 63% случаев, «полу» в 37%. Выбранное слово добавляется к фразе («Кошка сидит на диване»), и цикл с шага 0 повторяется, пока не будет выбран токен конца.

## Откуда берутся числа в векторах и матрицах

Все векторы слов, матрицы Wq, Wk, Wv, W_out и веса сети FFN сначала случайные. Тогда модель даёт бессмысленные вероятности.

При обучении ей показывают миллиарды фраз, например «Кошка сидит на … диване». Для каждой пары «контекст и настоящее следующее слово» модель считает вероятность настоящего слова. Ошибка измеряется функцией потерь (cross-entropy): `потеря = −ln p(настоящее слово)`. Если модель дала слову «диване» маленькую вероятность, потеря большая, и градиентный спуск немного подправляет все числа так, чтобы эта вероятность выросла.

После многих итераций модель сама научилась давать высокие вероятности подходящим словам. Никакая таблица вероятностей вручную не заполняется.

## Где в этой цепочке картинка (VLM)

У языковой модели с картинкой цепочка та же. Отличие только в шаге 2: добавляется cross-attention. Слова текста (запросы) смотрят на патчи картинки (ключи и значения) и забирают оттуда информацию. Картинка превращается в патчи кодировщиком (например ViT), затем патчи участвуют в attention вместе со словами. Дальше всё как раньше: вектор h, логиты, softmax, top-p, выбор слова.

## Сколько это стоит

| Операция | Цена | Пример |
|---|---|---|
| Логиты | O(d · V) умножений | d = 4096, V = 32 000: около 131 млн |
| Softmax | O(V) | 32 000 экспонент |
| Сортировка для top-p | O(V log V) | около 480 тысяч сравнений |
| Top-k через кучу | O(V log k) | меньше, чем полная сортировка |
| Self-attention | O(n² · d) | n = 576 патчей: 331 776 пар |
| Cross-attention | O(n_text · n_img · d) | 50 слов × 576 патчей: 28 800 пар |

## Словарь терминов

| Термин | Простыми словами |
|---|---|
| Токен | кусочек текста, которому в словаре соответствует номер |
| Embedding | вектор, то есть набор чисел, описывающий слово |
| Query, Key, Value | «что ищу», «чем представлюсь» и «что отдам» у каждого слова в attention |
| Attention | слово смотрит на другие слова и берёт у них информацию в нужной пропорции |
| Вектор контекста h | итог всех слоёв для последней позиции, смысл всей фразы |
| Логит | сырой балл слова, может быть любым числом |
| Softmax | превращает баллы в вероятности с суммой 1 |
| Температура T | делает выбор увереннее (T < 1) или случайнее (T > 1) |
| Top-k, top-p | фильтры, которые оставляют только лучшие слова-кандидаты |
| Cross-entropy | мера ошибки при обучении: −ln вероятности настоящего слова |
